# Rejected pilot

This partial EXP-0023 campaign is not admissible performance evidence.

Reason: repository compilation and test processes ran concurrently with measured arms. That can perturb host scheduling, request submission, and p99 latency. Four completed arm artifacts are preserved for debugging only; no paired scientific conclusion is drawn from them.

The campaign was stopped before pair 3 and will be rerun from a frozen build with no concurrent development workload.
