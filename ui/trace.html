Every chat request is mirrored to a second vLLM container running the Compute Sanitizer instead of CUPTI (the two can't share a process on this stack — see docs). Its reply is never shown; only its real block-entry events are, attributed to a request by matching the block index against that request's authoritative_packed_rows range — the same formula the offline exporter uses. The kernel's grid-shape validity precondition (grid.y=grid.z=1) is carried over as a structural assumption, not re-verified live.
